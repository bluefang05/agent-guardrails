Agent guardrails

A small coding-agent runner where every tool is allowlisted, writes are jailed to a workspace, budgets are enforced and a failed run rolls back what it wrote.

These transcripts are generated by npm run build:demo executing the real runAgent() against an in-memory workspace, a scripted model and a scripted command runner. No LLM calls, no shell and no network here. The repo's tests cover the same code paths.

Paths

Only src/ and tests/, extensions .ts .json .md. No .., no absolute paths, no .env.

Commands

npm testnpm run buildnpm run typechecknode --versiongit statusgit diffgit diff --stat

Writes

Max 32 KB per file, 96 KB per run, 4 files. Secret patterns (PEM keys, AWS and OpenAI-style keys) are refused.

Budgets

8 steps, 12 tool calls, 30 s wall clock. Any violation aborts and restores every file touched.

Fix a failing test

Read the implementation, write a fix, run the test command, finish. Every call is allowed, so the run ends with status finished.
